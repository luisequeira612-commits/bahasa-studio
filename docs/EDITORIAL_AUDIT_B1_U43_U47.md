### Observaciones

- U43 mantiene una distinción coherente entre condición/relación (kondisi, hubungan), dependencia (bergantung) e influencia (memengaruhi, berpengaruh).
- U44 distingue adecuadamente estimación (perkiraan, memperkirakan), posibilidad/potencial (kemungkinan, berpotensi) y previsión (diperkirakan), sin presentar las previsiones como hechos seguros.
- U45 mantiene una progresión coherente entre anticipación (antisipasi, mengantisipasi), prevención (pencegahan, mencegah) y evitación (menghindari).
- U46 distingue recursos y uso (sumber daya, penggunaan), ahorro (menghemat), eficiencia (efisien) y asignación (mengalokasikan).
- U47 reutiliza Peraturan mediante el ID canónico A1 y Mematuhi/Melanggar mediante sus IDs A2; la reutilización es coherente con el sistema de vocabulario previo. Prosedur y Tanggung jawab completan el nuevo bloque sin desalineaciones claras.
- No se modificó vocabulario, ejercicios, glosas, explicaciones, IndexedDB, backup JSON v3, trackers/CSV ni dependencias.
