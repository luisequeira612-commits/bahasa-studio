## Estado de verificación

- Las entradas de U1–U6 se crean con verification.status: not_checked y sources: [].
- Este bloque no afirma que cada lema haya sido cotejado individualmente contra CEFR-J o NGSL. La selección es una primera redacción pedagógica y requiere una pasada de trazabilidad por lema antes de cambiar estados.
- Las frases de ejemplo son originales para este curso. No se han copiado frases de Tatoeba ni de materiales comerciales.
- No se incorpora audio ni un campo POS nuevo: el contrato actual de vocabulario PT-BR no contiene esos campos. La voz Piper en_US-lessac-medium figura como candidata, no como audio generado o probado. Cualquier extensión de esquema/audio se propondrá por separado y no cambiará IndexedDB v1 ni backup JSON v3.
