# Revisión lingüística B1 U21–U24: causa, propósito y experiencias pasadas

Fecha: 7 de noviembre de 2026  
Rama: `feat/b1-u21-u24-cause-past-experiences-2026-11-07`

## Contenido
- U21: causa con `karena` y `sebab`; consecuencia con `oleh karena itu`, `sehingga`, `akibatnya`; `makanya` como conector coloquial.
- U22: finalidad con `supaya`, `agar` y `untuk + verbo` (estructura ya encontrada en A1/A2, ahora explicada sistemáticamente).
- U23: experiencias con `pernah`, `belum pernah`, `baru saja`, `sempat`, `telah` y `masih`. Se reutilizan IDs A2 para `pernah`, `baru saja` y `masih`.
- U24: narración temporal con `dulu`, `waktu itu`, `ketika`, `kemudian`, `setelah itu`; vocabulario narrativo A2 `pengalaman`, `perjalanan`, `liburan`.

## KBBI VI y contraste de fuentes
Se intentaron las entradas directas de KBBI VI para los 13 términos/expresiones nuevos. KBBI VI fue accesible en `karena`, `sebab`, `agar`, `sempat`, `telah` y `waktu`; las entradas directas para `sehingga`, `akibat`, `makanya`, `supaya` y `dulu` no estuvieron accesibles. `Oleh karena itu`, `belum pernah` y `waktu itu` se tratan como expresiones de varias palabras y no como lemas independientes. No se asigna `verified_primary`.

Fuentes gramaticales independientes usadas para `cross_checked_secondary`:
- Causa/consecuencia y propósito: Sneddon, *Indonesian: A Comprehensive Grammar* (https://life-with-dream.org/wp-content/uploads/2013/08/Indonesian_A_Comprehensive_Grammar.pdf); Kemdikbud, *Bahasa Indonesia bagi Penutur Asing Tingkat C1* (https://repositori.kemendikdasmen.go.id/198/1/BIPA%20C1%20PPSDK.pdf); Kemdikbud, *Petunjuk Praktis Berbahasa Indonesia* (https://repositori.kemendikdasmen.go.id/3420/1/Petunjuk%20praktis%20berbahasa%20indonesia.pdf); Kemdikbud, *Buku Penyuluhan Paragraf* (https://badanbahasa.kemendikdasmen.go.id/resource/doc/files/Buku_Penyuluhan_Paragraf.pdf).
- `makanya` y uso coloquial/discursivo: artículo académico sobre marcadores discursivos indonesios, *Linguistik Indonesia* (2013): https://ojs.linguistik-indonesia.org/index.php/linguistik_indonesia/article/view/13; ejemplos de registro informal contrastados con Sneddon y Kemdikbud.
- Aspecto y experiencias: Sneddon, *Indonesian: A Comprehensive Grammar* (https://life-with-dream.org/wp-content/uploads/2013/08/Indonesian_A_Comprehensive_Grammar.pdf); Elon.io, guía de aspecto y marcadores temporales: https://elon.io/grammar/indonesian/aspect-modality; DLI Indonesian Student Manual (https://www.yojik.eu/languages/DLI/Indonesian/Student%20Manuals%20%28Modules%201%20-%206%29/Indonesian%20Student%20Manual%20M1/M1L5student_correctionfinal_govtnored.pdf).
- `telah` se marca como más formal/escrito; `sempat` como oportunidad/tiempo disponible; `makanya` como coloquial. `akibatnya` se enseña como conector lexicalizado de resultado, no como lección productiva del sufijo `-nya`.
- Todos los términos nuevos quedan `cross_checked_secondary` con dos o más fuentes; no se afirma validación nativa ni calibración MCER/BIPA.

## Solapamiento con A1/A2
- A2 ya enseña explícitamente `pernah`, `baru saja`, `masih`, `ketika`, `kemudian`, `pengalaman`, `perjalanan` y `liburan`; se reutilizan sus IDs canónicos.
- A2 usa `karena` y `untuk` en ejemplos, pero no tiene una lección sistemática de causa/consecuencia ni de finalidad con `supaya/agar/untuk + verbo`; B1 amplía y organiza esas funciones.
- `belum pernah` se enseña como combinación de `belum` + `pernah`; `waktu itu` como expresión temporal; no se crea una segunda entrada para los lemas A2.
- No se modifica A1 ni A2.
