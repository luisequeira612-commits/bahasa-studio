# B2 U46 — Elipsis de palabras distintas del sujeto

**Fuente principal:** Sneddon, Adelaar, Djenar & Ewing (2010), *Indonesian: A Comprehensive Grammar*, 2.ª ed., §4.115, p. 377.

## Alcance
Cuando una acción o un estado ya se mencionó, la cláusula siguiente puede omitirlo y conservar el sujeto junto con la información nueva o contrastiva. No se elimina el contenido arbitrariamente: el antecedente discursivo permite recuperarlo.

## Ejemplos documentados
- «Saya sudah makan tapi mereka belum.» — se omite makan después de belum.
- «Majikannya tidak tahu ke mana dia pindah. Teman-temannya juga tidak tahu.» — la segunda cláusula recupera el contenido de ke mana dia pindah.

## Lecciones
1. Acción ya mencionada: makan … belum.
2. Contraste entre sujetos y acciones.
3. Información compartida entre dos cláusulas.
4. Identificar el elemento no repetido.
5. Explicar la recuperación del contenido omitido.

Cinco lecciones authored, 16 ejercicios (3/3/3/3/4), cuatro tipos. Sin vocabulario/IDs nuevos ni audio; se reutilizan los dos ejemplos documentados.

## Límites
U46 permanece oculta/no publicada. No se crean frases indonesias nuevas y el análisis se trabaja en español. No equivale a validación nativa ni certificación MCER/BIPA.
