# Revisión lingüística B1 U18–U20: condiciones, concesiones y contraste

Fecha: 7 de noviembre de 2026  
Rama: `feat/b1-u18-u20-conditionals-concessives-2026-11-07`

## Contenido
- U18: `kalau` y `jika` para condiciones posibles; `seandainya` para hipótesis; `asalkan` para un requisito suficiente.
- U19: `walaupun`, `meskipun` y `biarpun` para concesión; `biarpun` tiene un tono más conversacional/personal.
- U20: `tetapi` coordina cláusulas contrastivas dentro de una oración; `namun` introduce una oración que contrasta con la anterior. Se evita añadir automáticamente `tetapi` después de `meskipun` o `walaupun`.

## Solapamiento
La búsqueda de vocabulario en A1/A2 no encontró entradas explícitas para estos nueve conectores. Las apariciones de `kalau` y `tetapi` en el archivo principal son etiquetas de una lista temática de planificación, no lecciones A1/A2. No se modifica A1 ni A2.
